# 3.0.15 发布记录

修复侧边栏排序：鼠标按住入口后直接移动超过 8 像素即可拖动整行，长按拖动仍可用。禁用链接的原生拖拽，避免它抢占指针事件；单击入口仍会打开页面。首页与侧边栏中的操作说明已同步更新。

本地 Windows 安装脚本现从 `release/<版本号>/bundle/msi/` 读取对应安装包。本地构建脚本仍将安装包放入版本目录，并更新 `release/SJTU Canvas Helper.exe` 快捷入口；若旧可执行文件正在运行，可从版本目录打开新文件。

验证：前端 37 个测试文件、162 项通过，其中侧边栏覆盖整行直接拖动、图标长按移除与普通点击导航；TypeScript 类型检查和改动文件 ESLint 通过；Rust 离线测试 87 项通过、14 项按需跳过。Windows x64 的 EXE、MSI、NSIS 均已构建，SHA-256 与 `release/3.0.15/SHA256SUMS.txt` 一致，根目录便携版入口也与 3.0.15 版本文件一致。浏览器预览因缺少 Tauri 桥接接口而无法打开应用；尚需在安装后的桌面应用中人工确认拖动手感。
