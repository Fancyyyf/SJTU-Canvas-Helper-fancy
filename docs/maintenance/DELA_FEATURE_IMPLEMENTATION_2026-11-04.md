# Dela 参考功能实施记录（2026-11-04）

本次实现为独立代码实现，未复制 Dela 的 GPL 源文件。

## 已接入

- 正式课表：并入“日程管理”，不再单列导航。Rust 后端通过现有 jAccount Cookie 建立教学信息网会话；前端按账号、学年和学期缓存课表，迁移旧版课表缓存。日程页提供周/月视图、第一周周一设置、当前学期拉取状态、尝试和成功时间；内容相同则保留原缓存并记录检查，内容变化则更新。课程只读叠加在日历上，不写入或改动个人日程。
- TODO：按账号存储个人待办和 Canvas 学生作业。作业数据独立于现有 Canvas 日历缓存，收录无 DDL 作业；显示待完成、线下完成、已提交、已评分状态。单门课同步失败时保留该课程旧数据。
- 提醒：应用运行期间每五分钟检查未来 24 小时内到期的待办，对同一账号、同一待办、同一截止时间只提醒一次。首次同步建立基线，后续新增 Canvas 作业可触发系统通知。需要用户在 TODO 页面开启系统通知。
- 网页搜索：前端输入临时 Brave Search API Key，Rust 后端调用 Brave Web Search API，返回标题、链接、摘要。Key 不写入本地存储。
- Pi：Agent 页面可在自配的内置 Agent 与 Pi Agent 之间切换，聊天记录分开保存，并可新建对话。Pi 沿用设置中当前选中的 API Key、接口地址和模型，通过本机 Pi CLI 的会话文件保持连续对话；当前只接收当前账号的日历与 TODO 快照，禁用内建工具和项目资源。内置 Rig Agent 保留 Canvas 工具能力。

## 当前边界与验证

- 课表需要有效的校园网页登录态；Canvas Token 不能替代。真实教学信息网请求须用用户已登录的账号验证。
- Pi 模式依赖本机 `pi` 命令，预览程序未捆绑 Pi 或 Node 运行时。Pi 模式没有 Canvas 工具桥接和流式输出；当前会话由本机 Pi 会话文件维持。
- 系统提醒仅在应用运行时检查，不保证应用退出期间准时送达。
- 网页搜索需要用户自己的 Brave Search API Key；未接入水源自动抓取。水源社区当前协议限制非官方脚本客户端。
- 课程资料引用与轻量笔记未纳入本次范围。

## 后续迭代

1. 在真实校园账号上验证课表 SSO、第一周日期、教室与节次字段，补充登录失败的自助恢复入口。
2. 将 TODO 与课表缓存移至原生账号隔离存储，统一日历数据投影和提醒设置。
3. 为 Pi 打包运行时并建设受控 Canvas 工具桥接、流式输出与独立会话。
4. 如有需要，再扩展搜索供应商和内容抓取；先确认目标服务的接口使用条款。
