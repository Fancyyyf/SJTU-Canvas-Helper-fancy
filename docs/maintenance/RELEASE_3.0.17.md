# App v3.0.17

## 新功能

- 日历支持新建、修改、删除本地个人日程，以及从 ICS 文件预览并一键导入。个人日程按 App 账号保存在本机；旧本地记录会自动迁移。
- 应用启动和日历页手动更新时，从 Canvas 同步课程作业的截止时间与提交状态。同步失败时保留已有的本地作业记录。
- Canvas Agent 可查询本地日历，并按用户明确要求创建、修改或删除个人日程。课程、作业、文件、讨论等查询保持只读；不开放其他学生的提交和成绩数据。

## 体验修复

- Agent 每次收到消息时获取用户本机的发送时间与时区偏移。在作业截止、DDL、待办和日程问题中，“最近 7 天”默认指未来 7 天，无需反问日期或方向；明确指定过去或其他范围时按用户要求处理。
- 提供 `yarn app:dev` 和 `yarn build:preview:local`，方便在不发布 Release 的情况下运行和保留本地调试版本。

## 下载

Windows x64 用户优先选择 `SJTU.Canvas.Helper_3.0.17_x64-setup.exe`；便携版选择 `SJTU.Canvas.Helper_3.0.17_x64_portable.zip`。附件中的 `SHA256SUMS.txt` 可用于校验下载文件。
